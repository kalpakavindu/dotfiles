# Setting up Sway Notification Client

Ensure installed:
- **`swaync`**
- `sassc`
- `playerctl`

## Setup
Symlink this folder with `~/.config/swaync`.

```bash
rm -rf '/home/kalpakavindu/.config/swaync'
sudo ln -s -n '/home/kalpakavindu/Source/dotfiles/linux/swaync' '/home/kalpakavindu/.config/swaync'
```
